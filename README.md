# 摄影师装备舱

给客户用的摄影师配置工具，按手机竖屏设计，界面参考吃鸡背包。

客户从开场页进入，一个空白摄影师落地，然后按 7 步引导配置：**拍多久 → 选摄影师 → 机身·镜头 → 灯光 → 视频·航拍 → 团队·服务 → 确认订单**。每选一件器材，它会带着冲击波、火花、画面震动和音效直接「砸」到摄影师身上对应的位置（相机在手、镜头挂腰带、背包和三脚架在背上、电影机在肩上、GoPro / 无线麦 / Pocket 3 在胸前），灯架、稳定器、航拍、助理、化妆师和服装架放在周围。装备满载度从 0% 加到 100%，满配时出现「全副武装」。

声音全部由代码实时合成（开场、背景音乐、装备、服务、摄影师升级、卸下、满配），右上角可以分别关掉音乐和音效。

## 打开方式

人物模型 `assets/photographer.glb` 要通过网页服务器加载，直接双击 `index.html` 打不开模型（会退回简易人形）。本地预览：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

部署到任意静态网站（GitHub Pages、腾讯云 COS、阿里云 OSS 等）即可。

## 改价格、改文案

全部在 `index.html` 里 `配置区` 那一段：

| 常量 | 内容 |
| --- | --- |
| `BRAND` / `CITY` | 品牌名、城市 |
| `DURATIONS` | 时长套餐：价格、含精修张数、建议景点 |
| `PHOTOGRAPHERS` | 摄影师等级：从业年限、服务客户数、好评率、服务意识（强 / 中等）、每小时加价、成片展示；`look` 是 3D 形象（发型、发色、身高、肤色、衣服颜色），`photo` 是真人照片地址 |
| `SERVICE_LEVELS` | 标准服务（服务意识中等）/ 管家服务（服务意识强） |
| `ITEMS` | 器材与服务：名称、型号、加价、六维加成、注意事项 |
| `DISCOUNTS` | 加购满减 |
| `PRESETS` | 四个一键套餐 |
| `GRADES` | 战斗力评级门槛 |

## 两种模式

第一步顶部可以切换：

- **旅拍写真**（按小时）：桂林旅拍、写真，7 步配置，下面的「价格逻辑」说的是这个模式
- **活动 · 会议直播**（按人天）：价格来自《光感影视｜十月活动设备与服务报价（2026.09.29 v1）》，4 步配置：活动天数（可加半天彩排）→ 拍摄岗位 → 直播设备 → 报价单。岗位和设备可以加减数量，报价单按表格格式输出（编号、计费方式、小计、未税合计、人民币大写、可选 1% 开票税点、每日到场人数）。点「十月大会」参考案例，算出来正好是未税 ¥58,250 / 含税 ¥58,832.5，和原表一致

活动模式的价格都在 `index.html` 的 `EV_ITEMS`（岗位和设备）、`EV_FREE`（已包含项目）、`EVENT_TAX`（税点）里改。计费方式：`perDay` 人天（彩排算半天）、`showDay` 只算活动日、`fullDay` 整天（彩排算 1 天）、`once` 一次性。

## 画面与画质

- 渲染：摄影棚环境光（顶部柔光箱 + 两侧条灯）、主光柔光箱、冷色轮廓光、体积光束和浮尘、环境光遮蔽（GTAO）、泛光、4 倍抗锯齿、电影感调色（暗角、颗粒、轻微色差）
- 材质：皮革颗粒握把、滚花对焦环和拨盘、碳纤维稳定器轴臂、带彩色镀膜反光的镜头玻璃、品牌字样贴花
- 器材外形参考了实物照片和官方尺寸（A7 IV、A7R V、GFX100 II、X2D、FX6、FX3、FS5、RS 4 Pro、Mavic 3 Pro、Godox V1 / AD600、BMD 导播台）
- 画质分高 / 中 / 低三档：电脑默认高，手机默认中；开始后会测帧率，太卡自动降一档；右上角「画质」按钮可以手动切换并记住

## 器材模型渲染图

`assets/gear-renders/` 里是每件器材 3D 模型的渲染图（512×512 透明底 PNG），`assets/gear-overview.png` 是总览。模型都是在页面里用代码搭的简化版，用来示意，不是品牌官方模型。重新导出：在页面控制台运行 `gearRenders(512)`，返回每件器材的图片数据。

## 价格逻辑

- 时长价已含：新锐摄影师、Sony A7 IV + 24-70mm F2.8、反光板、底片全送、基础调色、精修
- 摄影师等级按「每小时加价 × 时长」计算
- 器材、服务按场次计价；加购满 ¥300 / ¥600 / ¥1000 分别减 ¥30 / ¥80 / ¥150
- 订单里列出免费包含项目的参考价，并提示「再加多少立减多少」
- 镜头带到 3 支以上，自动送双肩摄影包

## 换成真人摄影师

1. 把照片放进仓库（比如 `photos/p1.jpg`），在 `PHOTOGRAPHERS` 里填 `photo: 'photos/p1.jpg'`，客户点「真人照片」就能看到
2. 对照照片调 `look`：`hair` 可选 `short` 短发 / `long` 长发马尾 / `bun` 盘发 / `cap` 棒球帽 / `beanie` 毛线帽，`height` 是身高倍数，`skin` 肤色，`outfit` 上衣颜色
