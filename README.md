# 摄影师装备舱

给客户用的摄影师配置工具，界面参考吃鸡背包。客户按 4 步配置：**拍多久 → 选摄影师 → 加器材 → 加服务**。中间的 3D 写实摄影师一开始只穿简单衣服、手里拿着标配相机，客户每加一件器材，它就从装备箱飞到身上的对应位置（镜头挂腰带、背包和三脚架在背上、闪光灯在热靴、GoPro 在胸前），灯架、航拍、助理、化妆师和服装架放在周围。

## 打开方式

人物模型 `assets/photographer.glb` 要通过网页服务器加载，直接双击 `index.html` 打不开模型（会退回简易人形）。本地预览：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

部署到任意静态网站（GitHub Pages、腾讯云 COS、阿里云 OSS 等）即可。

## 改价格、改文案

全部在 `index.html` 里 `配置区` 那一段：

| 常量 | 内容 |
| --- | --- |
| `BRAND` / `CITY` | 品牌名、城市 |
| `DURATIONS` | 时长套餐：价格、含精修张数、建议景点 |
| `PHOTOGRAPHERS` | 摄影师等级：从业年限、服务客户数、好评率、服务意识（强 / 中等）、每小时加价、成片展示 |
| `SERVICE_LEVELS` | 标准服务（服务意识中等）/ 管家服务（服务意识强） |
| `ITEMS` | 器材与服务：名称、型号、加价、六维加成、注意事项 |
| `DISCOUNTS` | 加购满减 |
| `PRESETS` | 四个一键套餐 |
| `GRADES` | 战斗力评级门槛 |

## 价格逻辑

- 时长价已含：新锐摄影师、Sony A7 IV + 24-70mm F2.8、反光板、底片全送、基础调色、精修
- 摄影师等级按「每小时加价 × 时长」计算
- 器材、服务按场次计价；加购满 ¥300 / ¥600 / ¥1000 分别减 ¥30 / ¥80 / ¥150
- 订单里列出免费包含项目的参考价，并提示「再加多少立减多少」
- 镜头带到 3 支以上，自动送双肩摄影包
