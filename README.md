# 摄影师装备舱

一个像游戏换装一样的摄影师配置工具。客户（或同行）从左边的装备库点选器材、灯光、航拍和团队，3D 场景里的空白摄影师会被一件件装上装备，报价、战力、段位和样片示意实时变化。

## 打开方式

直接用浏览器打开 `index.html`（需要联网加载 Three.js 和字体）。

## 改价格、改品牌

都在 `index.html` 里 `配置区` 那几行：

- `BRAND`：左上角品牌名
- `BASE`：基础出勤项目和价格
- `GEAR`：每件装备的名称、型号、稀有度（N/R/SR/SSR）、加价 `price`、六维加成 `st`（q 画质、l 光影、m 氛围、v 动态、a 视角、s 服务）
- `PRESETS`：轻装 / 标配 / 旗舰 / 满配 四个一键套餐
- `TIERS`：段位名称和门槛

## 功能

- 34 件装备，分 7 类，每件都有独立 3D 模型，从装备箱飞到身上
- 机身四选一，其余可叠加；装满 31 件触发「全副武装」
- 战力、段位、六维雷达图
- 按配置生成的样片示意（画质、布光、虚化、烟雾、调色、电影宽银幕、航拍画中画）
- 交付清单和报价单，可复制
- 一键生成战绩海报
- 点装备箱可以随机「开箱」
